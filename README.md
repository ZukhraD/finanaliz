# Финансовый анализ компаний и групп РК

Веб-версия анализатора: баланс, ОПиУ, ДДС (стандартная форма МФ РК), загрузка форм из Excel, свод группы,
коэффициенты, прогноз денежного потока до 84 месяцев (база и стресс), проблемы с подсказками, заключение в Word.

© 2026 Создан ОФКК Костанай

## Как устроено
- Одна страница `index.html` без сервера, без базы данных и без внешних библиотек.
- Данные клиентов хранятся **только в браузере пользователя** (localStorage) и никуда не отправляются:
  сетевые запросы запрещены политикой безопасности (Content-Security-Policy) и в самой странице, и в `vercel.json`.
- Резервная копия клиента — кнопка «Файл» (.json); такие файлы **не загружайте в репозиторий** (см. `.gitignore`).

## Разработка
Исходники — в `src/`. После правок пересоберите страницу:
```
python3 build.py      # собирает index.html из src/
```

## Публикация на Vercel
Vercel → Add New → Project → Import этого репозитория → Framework Preset: **Other**, Build Command — пусто,
Output Directory — `.` (корень) → Deploy. Каждый push в ветку main публикуется автоматически.

## Налоги и Банк

**Налоги** — декларации (100.00, 910.00, 300.00, 200.00 и др.) в PDF или Excel; суммы сверяются с ОПиУ.

**Банк** — выписки по счетам и справки об оборотах в PDF, Excel (.xlsx) или CSV. По выпискам считаются чистые кредитовые обороты: из поступлений исключаются кредиты и займы, конвертация (продажа валюты), переводы собственных средств, возвраты платежей, финансовая помощь, субсидии (кроме ГЧП), штрафы и пени, вознаграждение, страховые выплаты и взносы наличными (кроме инкассации и поступлений по договорам с ИП). Классификация — по назначению платежа, КНП и БИН отправителя; каждую операцию можно переопределить вручную. Валюта пересчитывается по курсу НБ РК на дату поступления (курсы вводятся или загружаются файлом).

PDF читается прямо в браузере, без библиотек и сети (`src/app6.js`); распознавание документов — `src/app7.js`; сверка и интерфейс — `src/app8.js`.
